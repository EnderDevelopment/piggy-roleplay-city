# Piggy Roleplay City

Piggy Roleplay City is a Minecraft plugin designed to enhance the roleplay experience on your server. It includes features like secret skins, customizable skins, and roleplay commands to bring your server to life. This plugin is perfect for servers looking to create immersive and engaging roleplay environments.

## Install

1. Download the plugin JAR file from the releases section of this repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your server to load the plugin.

## Use

1. Join your Minecraft server and start roleplaying.
2. Use the `/ciao` command to greet other players.
3. Customize your character with secret skins and skins to enhance your roleplay experience.
